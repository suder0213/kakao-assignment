# 3단계 학습 로그 — 일간 뷰

## 구현 요약

- 화면 상단에 날짜 네비게이터 추가 (이전 / 날짜 텍스트 / 오늘 뱃지 / 다음)
- `currentDate` 상태로 현재 선택된 날짜 관리, 앱 시작 시 오늘 날짜로 초기화
- Todo 생성 시 `date: 'YYYY-MM-DD'` 필드를 함께 저장
- `getFilteredList()` 에서 날짜 필터 → 상태 필터 순서로 2단계 적용
- 날짜 이동 시 필터를 '전체'로 초기화

## 심화 정리

### 날짜를 Date 객체가 아닌 'YYYY-MM-DD' 문자열로 저장한 이유

`Date` 객체는 시간 정보(시/분/초/밀리초)를 함께 가진다. 그래서 같은 날이라도 생성 시점에 따라 값이 달라 `===` 비교가 불가능하다.

```js
new Date() === new Date() // false — 생성 시점이 달라 값이 다름
```

`'YYYY-MM-DD'` 문자열은 날짜만 담고 있어서 단순 문자열 비교로 같은 날인지 확인할 수 있다.

```js
'2026-06-01' === '2026-06-01' // true
```

### 날짜 필터와 상태 필터를 2단계로 적용한 이유

두 조건을 한 번에 쓰면 읽기 어렵고 조건 변경 시 수정이 번거롭다.

```js
// 단계를 나눠서 적용
const byDate = todoList.filter((item) => item.date === dateKey); // 1단계: 날짜
return byDate.filter((item) => !item.completed);                 // 2단계: 상태
```

날짜 필터와 상태 필터가 독립적으로 분리되어 있어 각각 수정하기 쉽다.

### HTML 엔티티

특수문자를 코드로 표현하는 방식. `<`, `>` 같은 HTML 예약 문자를 그대로 쓰면 브라우저가 태그로 해석하기 때문에 엔티티로 표기한다.

```
&#8249; → ‹    &lt; → <
&#8250; → ›    &gt; → >
```

### `padStart(2, '0')`

`getMonth()`, `getDate()` 는 한 자리 숫자를 그대로 반환한다 (ex. `5`, `3`). `padStart(2, '0')` 로 앞에 `0`을 채워 두 자리로 맞춘다 (ex. `'05'`, `'03'`). `YYYY-MM-DD` 포맷을 일정하게 유지하기 위해 필요하다.

```js
String(5).padStart(2, '0')  // '05'
String(12).padStart(2, '0') // '12' — 이미 두 자리라 변화 없음
```
